# 科研数据集访问申请与引用追踪系统

学校科研数据管理平台：公开数据集目录、按用途申请访问、审批后按授权范围下载、成果引用登记与追踪。

## 技术栈

- **后端**：PHP 8.4 + Laravel 13（Eloquent ORM + SQLite），Sanctum 令牌认证
- **前端**：React 19 + Vite + React Router
- **数据文件**：本地 CSV，保存在 `backend/storage/app/datasets/`
- **邮件**：模拟发送（`MAIL_MAILER=log`，写入 `backend/storage/logs/laravel.log`）

## 一键启动

```bash
bash start.sh
```

脚本会自动：准备 PHP 与 Composer（无系统 PHP 时下载静态构建）→ 安装后端依赖 → 迁移并播种 SQLite → 安装前端依赖 → 同时拉起两个服务。

- 前端页面：http://127.0.0.1:5173
- 后端 API：http://127.0.0.1:8000

## 核心流程

1. **公开目录**：任何人可浏览数据集与公开字段预览；受限字段的名称与取值都不会出现在公开接口中（只显示数量）。
2. **申请**：研究员登录后选择**数据集版本 + 字段范围 + 使用期限**，填写用途提交申请。
3. **审批**：管理员在后台批准（可收窄字段，不能超出申请范围）或拒绝（需填写原因）。批准后生成授权快照（版本 + 字段 + 期限）。
4. **下载**：研究员在「我的下载」为生效中的授权生成下载链接。下载内容严格限定在授权版本与授权字段内。
5. **引用登记**：发表成果后登记引用，系统生成引用编号（`CIT-年份-序号`）并关联**授权实际使用的数据版本**。

## 安全与一致性规则（均有自动化测试覆盖）

- **字段权限**：下载接口的字段永远取自授权快照；`?fields=` 只能收窄不能扩大，传入未授权字段（含 `fields[]=` 数组形式）返回 403。
- **版本锁定**：授权固定在审批时的版本；`?version=`、`?dataset_version_id=` 等参数一律被忽略。
- **数据集更新不扩大授权**：发布新版本只新增版本记录，旧授权仍指向原版本、原字段；新版本的字段需重新申请。
- **链接失效**：授权被撤回（下载令牌同步删除）或使用期限到期后，旧下载链接立即返回 404/410。
- **拒绝后须重新申请**：被拒绝的申请不可再变更状态，改变用途需提交新申请。
- **引用保留**：授权撤回或到期后，已登记的成果引用继续保留，也仍可补登。

## 运行测试

```bash
cd backend
../../.tools/php artisan test        # 或系统 php artisan test
```

22 个特性测试覆盖：目录预览不泄露受限字段、申请-审批-下载全流程、字段越权（含参数篡改）、版本切换、数据集更新后旧授权范围不变、撤回/到期后旧链接失效、引用保留与冒名登记拦截。
